# 解码测试数据

`codec-vectors.json` 包含 100 帧人工合成的 ICOV1 数据：静音、997 Hz 正弦波、谐波和确定性噪声各 25 帧，采样率为 16 kHz。

参考 PCM 由定点解码器生成。测试将浮点解码结果与参考 PCM 比较，检查采样数、波形相关性、音量和静音电平。

测试数据与本文档采用项目的 MIT 许可。

`test_reconnect.ps1` 使用模拟设备检查离线等待、唤醒、快速重连、有限重试和清理。`test_ui_lifecycle.ps1` 使用模拟后台检查等待状态、恢复连接、暂停、托盘、退出和快捷键参数；两个检查均不操作真实蓝牙或键盘。
